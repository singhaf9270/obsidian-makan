# Makan · ماکان

## What's new in 2.0.0

Makan 2.0.0 is a major customization update, significantly expanding the Style Settings panel and giving you finer control over the appearance of your workspace.

### New presets

- Added overall theme and reading-layout presets for quickly changing the look and feel of your workspace.
- Added presets for surfaces, headings, tags, tables, callouts, and task styles.
- Added more controls for choosing and combining visual styles.

### Checkbox and task styling

- Customize checkbox shape, corner radius, size, and alignment.
- Set separate background and border colors for checked and unchecked checkboxes.
- Customize the checkmark color, hover background, hover border, and focus ring.
- Adjust checkbox glow and spacing.
- Fine-tune completed-task cards, including background, text, border, radius, hover color, and highlight offsets.
- Option to disable the completed-task card.

### Folder colors

- Enable or disable folder coloring.
- Choose the folder coloring mode and set a custom solid color.
- Customize folder label colors and hover brightness.

### More workspace and typography controls

- Customize heading letter spacing and text transformation.
- Control text justification, hyphenation, text rendering, and paragraph indentation.
- Adjust active-tab indicator placement and sidebar transparency.
- Customize header shadows and scrollbar width and thumb color.
- Fine-tune link underline style, thickness, and offset.

### More detailed component styling

- **Code**: Customize code block radius, borders, line height, and inline code background.
- **Tables**: Choose table presets and control zebra stripes, bold headers, and hover highlighting.
- **Callouts and quotes**: Choose callout presets and customize quote font style and background.
- **Lists**: Customize bullet color, shape, and size.
- **Images**: Configure image shadows and maximum image height.

## Features

- Light and dark mode support.
- Six built-in color palettes: Ocean, Mint, Lavender, Rose, Amber, and Slate.
- Extensive customization through the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin.
- Custom colors for backgrounds, text, accents, headings, links, tags, code blocks, tables, callouts, and workspace elements.
- Independent typography controls for the editor, interface, and code.
- Customizable reading width, line height, paragraph spacing, and interface density.
- Customizable active-tab colors and file-explorer row height.
- Detailed checkbox, completed-task, and folder-color customization.
- Persian (RTL) and English (LTR) friendly styling.
- Animated completed-task feedback in Editing and Reading views.
- Reduced-motion accessibility support.
- No external assets, scripts, fonts, or network requests.

## Installation

### From this repository

1. Download `theme.css` and `manifest.json`.
2. In your vault, open `.obsidian/themes/`.
3. Create a folder named `Makan`.
4. Place both files inside that folder.
5. In Obsidian, open **Settings → Appearance → Themes** and select **Makan**.

### Recommended: Style Settings

Install the **Style Settings** community plugin to access Makan's full customization panel:

1. Open **Settings → Community plugins → Browse**.
2. Search for **Style Settings** and install it.
3. Enable the plugin.
4. Open **Settings → Style Settings → Makan**.

From there, you can customize the theme's colors, typography, headings, checkboxes, completed tasks, folders, tables, callouts, and workspace.

## Updates

Download the latest `theme.css` and `manifest.json` from this repository and replace the existing files in `.obsidian/themes/Makan/`.
